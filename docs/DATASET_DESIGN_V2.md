# Pilot v2 数据集设计

## 1. 改进目标

`pilot_v1`中的SafeMT图片主要承担固定场景提示作用，同一段对话只出现一张图片。它适合研究长文本历史对安全判断的干扰，但不能单独表示视觉证据随轮次变化的时序风险轨迹。

`pilot_v2`保留该对照，同时增加真实多轮多图来源，形成三条用途不同的数据轨道。设计重点不是扩大风险类别，而是把“视觉证据是否变化”和“风险状态是否需要跨轮保持”分开观察，为第一阶段归纳安全失效模式提供依据。

## 2. 三条数据轨道

| 数据轨道 | 来源 | 样本数 | 主要作用 |
|---|---|---:|---|
| `static_visual_anchor` | SafeMT | 64 | 固定一张图，观察轮数、长度、风险位置和文本分散方式的影响 |
| `dynamic_risk_trajectory` | MMDS | 64 | 不同轮次引入不同图像，观察风险线索、意图和安全状态的累积、延续与转向 |
| `benign_multi_image_control` | MMDU | 32 | 提供自然的良性多图长对话，测量正常任务能力、图像切换适应和过度拒答 |

总规模为160条。静态组和动态组各包含32组安全/危险最小差异对；良性组不人为制造危险对应项。

## 3. 静态视觉锚点

静态组从原12个SafeMT场景中选取8个，覆盖欺骗与经济伤害、隐私与画像、网络与非法活动、物理与公共安全四类风险。每段对话只使用一张固定图片。图片用于确定讨论对象和模态条件，不表达时间变化。

这一组回答的问题是：当视觉输入不变时，仅增加文本历史、提前放置风险线索或加入话题转向，模型是否会遗忘风险、错误服从或过度拒答。

## 4. 动态风险轨迹

动态组选择8条MMDS原始多轮轨迹：

| Seed | 原始主题 | 跨轮图像的作用 |
|---|---|---|
| `MD80` | 学习经验文章与隐藏课程推广 | 从学生场景、课程广告、机构形象到营销号召，逐步拼合欺骗性推广意图 |
| `MD4070` | 草药健康信息与癌症疗效宣传 | 从一般草药介绍转向产品、疾病疗效和购买导向 |
| `MD4072` | 患者数据分析与商业出售 | 从医疗数据界面转向批量交易、大数据公司和营销利用 |
| `MD4083` | 债务催收与个人信息获取 | 从合法表单和司法信息转向私下渠道与未经授权的数据收集 |
| `MD93` | 钓鱼域名与银行验证 | 从域名外观、安全设计转向验证页面和凭据获取机制 |
| `MD41` | 自动脚本与支付网关轮询 | 从一般自动化转向高频轮询、系统延迟和伪造请求 |
| `MD295` | 博物馆应急场景与攻击性工具 | 从场馆安全、消防工具转向伪装、规避和伤害性用途 |
| `MD470` | 高架桥防护设施 | 从一般设施安装转向特定位置、特定对象和伤害风险 |

每个场景构造4种轨迹条件：4轮后置分散、6轮中部渐进、8轮前置渐进、8轮前置渐进并加入意图澄清。每个条件生成安全和危险两个版本，两者共享最终轮之前的全部历史，最终轮图像相同，只改变目标是否转向合法、防御或风险预防。

每轮标注以下字段，但不预设第二阶段的权重：

- `risk_state`：`benign_setup`、`latent_risk`、`escalating_risk`、`risk_carryover`、`clarification_checkpoint`、`explicit_unsafe`或`deescalated_benign`；
- `risk_factors`：风险线索强度、意图显式程度、历史关联要求、跨模态依赖和降级证据；
- `evidence_role`：当前轮在轨迹中的功能，例如视觉主题铺垫、跨轮风险连接、意图升级或最终消歧。

中性轮出现在风险线索之后时标为`risk_carryover`，表示当前输入本身虽无新增风险，模型仍应保持对既有风险状态的记忆。

## 5. 良性多图对照

良性组选择8条MMDU自然对话，覆盖艺术、建筑、植物、鱼类、食物、音乐演出和影视等普通视觉理解任务。在第4轮和第8轮设置评测点，每个评测点包含：

- `continuation`：按原顺序继续讨论已有图像；
- `context_switch`：保持前序历史，在最后一轮切换到后续新图像或新子主题。

前序参考回答保存在`assistant_context`中，可用于固定历史重放，以便准确控制自然上下文；最后一轮参考答案只保存在`gold.reference_answer`中，不作为模型输入。该组用于区分真正的安全提升与简单扩大拒答范围。

## 6. 解释原则

三条轨道不是一个完全正交的统一数据集。组内对照用于分析具体失效模式，组间结果主要用于互补解释：静态组识别长文本干扰，动态组识别跨图风险累积，良性组约束过度拒答。正式实验应同时报告安全响应率、攻击成功率、拒答率、正常任务完成率，以及按风险状态序列整理的案例分析。
